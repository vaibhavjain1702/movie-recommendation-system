# Movie Recommendation System

Two parts of one coursework project on movie discovery and recommendation.

| Folder | What it is |
|---|---|
| [`website/`](website/) | Responsive movie discovery website built on the TMDB API: browse, search and filter movies. See its [README](website/README.md) for setup (you must supply your own TMDB API key in `js/config.js`). |
| [`notebooks/`](notebooks/) | Exploratory data analysis and a content-based movie recommender in Jupyter notebooks. See its [README](notebooks/README.md) for the dataset the notebooks expect. |
